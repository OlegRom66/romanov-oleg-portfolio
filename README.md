# ROMANOV OLEG • ИИ-ТВОРЧЕСТВО

Премиум портфолио на Next.js + Tailwind CSS + Framer Motion.

## Что уже сделано

- Красивый Hero (главная страница)
- Экран выбора категорий в высоком уровне
- Тёмная премиум-тема
- Плавные анимации
- Адаптивная вёрстка

## Как запустить у себя

### 1. Установи Node.js (если ещё нет)
Скачай LTS с https://nodejs.org (версия 20 или выше)

### 2. Открой терминал в папке проекта и выполни:

```bash
npm install
```

### 3. Запусти в режиме разработки:

```bash
npm run dev
```

Открой в браузере: http://localhost:3000

### 4. Когда будешь готов выкладывать:

```bash
npm run build
```

Потом деплой на Vercel (самый простой способ):
1. Зарегистрируйся на vercel.com
2. Подключи GitHub репозиторий
3. Vercel сам всё соберёт
4. Привяжи свой домен romanov-oleg.site в настройках проекта

## Структура

```
src/app/
├── page.tsx              ← Главная (Hero)
├── categories/page.tsx   ← Выбор категории
├── category/[slug]/     ← (будет) страница категории
└── layout.tsx
```
